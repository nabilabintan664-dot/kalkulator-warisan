# ⚖️ Kalkulator Waris Islam (Faraidh)

Kalkulator pembagian waris berdasarkan syariat Islam, sesuai Al-Qur'an Surah An-Nisa ayat 11-12.

## 🕌 Fitur
- Hitung bagian suami, istri, ibu, ayah
- Hitung bagian anak dengan rasio 2:1 (laki : perempuan)  
- Tampilan modern dan responsif
- Mudah digunakan

## 🛠 Teknologi yang Digunakan
- Python 3.x
- Streamlit

## 📖 Referensi
- Al-Qur'an Surah An-Nisa ayat 11-12
- Algoritma Al-Khawarizmi (Al-Jabr & Al-Muqabalah)
- Ilmu Faraidh
